# ✨ EventGenie — GenAI Event Planning Assistant

An intelligent, full-featured AI event planning web application designed to organize weddings, birthdays, and community events with dynamic budgets, interactive countdowns, vendor checklists, and curated AI-powered recommendations.

🌐 **Live Demo:** [https://eventgenie-ai-ten.vercel.app](https://eventgenie-ai-ten.vercel.app)

---

## 🌟 Features

- **Multi-Event Support**: Tailored planning workflows for:
  - 💍 **Weddings** (guest tracking, milestone timelines, custom vendors)
  - 🎂 **Birthdays** (themes, party timelines, activity checklists)
  - 🤝 **Community Events** (volunteers, permits, logistics, community goals)
- **📊 Dynamic Budget & Allocation**:
  - Auto-calculated budget category distributions
  - Interactive canvas donut chart with responsive allocation numbers
  - Add, edit, and delete custom expense items
- **⏱️ Live Countdown & Progress**:
  - Real-time countdown timer to the big day
  - Milestone checklists with completed progress tracking
- **🏪 Vendor Hub**:
  - Category-based vendor checklists with booking toggles
  - Budget estimation and vendor status management
- **🤖 GenAI Assistant**:
  - Context-aware AI assistant providing personalized recommendations
  - Theme generation, dietary catering tips, venue selection, entertainment ideas, and favors
- **💾 Local Persistence & Export**:
  - Automatically saves state to `localStorage`
  - Export complete event plan to formatted text file

---

## 🛠️ Tech Stack

- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Design System**: Dark glassmorphism, HSL color tokens, Outfit & Inter typography
- **Deployment**: Vercel

   ```bash
   git clone https://github.com/Kumar3421/EventGenie.git
   ```

   ```bash

   ```
